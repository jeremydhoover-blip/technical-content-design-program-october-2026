# Week 2: Learning Objectives

By the end of this session you will be able to:

- Read and interpret Markdown, JSON, and YAML files without prior programming experience
- Explain why structured content matters for AI systems that read and use that content
- Make a targeted change to a content file in your fork and understand what you changed
- Write a clear, specific commit message that describes the change (not just "update")
- Execute the full git workflow: branch → edit → add → commit → push
- Open a pull request on your own fork and write a useful PR description
- Read the automated check results, merge your PR, and update your local main branch
