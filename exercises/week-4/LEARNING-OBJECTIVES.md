# Week 4: Learning Objectives

By the end of this session you will be able to:

- Describe what evaluating AI output means in practical terms and explain why vague criteria don't work as evals
- Write at least three specific, testable eval criteria in `content/evals.json`, and run them with `npm run evals`
- Explain what CI/CD stands for and identify where content changes fit in a deployment pipeline. Point to the workflow in this repo that runs your checks
- Present your content system in ContentLab and explain a criterion and test result in Evaluations
- Distinguish automated criterion checks from judgments about voice, meaning, and persona fit
- Revise copy using failed checks and your feedback, then save and evaluate it again
- Connect the technical skills built across the program to your existing content design practice
- Identify one concrete way you would extend or improve your content system for a real product
