# Week 3: Learning Objectives

By the end of this session you will be able to:

- Explain what a context window is and why its size matters for AI-assisted writing tasks
- Describe what a token is and roughly how content length relates to token count
- Write a system prompt that produces meaningfully different output than an unprompted request
- Describe what "agentic" means in practical terms: an AI that takes a sequence of actions, not just a single response
- Connect their structured content files to AI system behavior: better structure produces more usable output
- Give an AI assistant file context in VS Code, using attached files, an instructions file, or a skill
- Run `npm run prompt` and read the token count for their content system
