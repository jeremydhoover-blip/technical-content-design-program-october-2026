# Week 3: Learning Objectives

By the end of this session you will be able to:

- Explain what a context window is and why its size matters for AI-assisted writing tasks
- Describe what a token is and roughly how content length relates to token count
- Write product instructions and check AI responses against your rules, comparing results with and without your product files
- Describe what "agentic" means in practical terms: an AI that takes a sequence of actions, not just a single response
- Explain how the files your assistant reads affect its response, using evidence from your comparison
- Give your chosen coding assistant the relevant files and check which ones it reads
- Run `npm run prompt` and explain its estimated token count
- Save comparison copy as test cases in `content/evals.json` and inspect the applicable checks in Evaluations
