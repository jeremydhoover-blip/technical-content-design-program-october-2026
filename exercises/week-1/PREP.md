# Before Week 1

---

## Read

Read GitHub's overview of what a repository is:  
[About repositories (GitHub Docs)](https://docs.github.com/en/repositories/creating-and-managing-repositories/about-repositories)

This will give you the vocabulary you need to follow along in session. You don't need to understand everything. Just get a sense of what a repository is and how it differs from a regular folder.

---

## Do

Find a website or app you use regularly. It could be anything. Pick one piece of copy in it: a button label, an error message, a tooltip, a confirmation dialog.

Write one sentence answering this question: where do you think that copy lives? Is it in a design file? A database? A code file? Something else?

There's no wrong answer. You'll revisit this at the start of Week 1.

---

## What to have ready

Make sure these are installed and working before the session. If you run into trouble, check the [Setup guide](../../docs/SETUP.md) or reach out in the UXCC community.

- **VS Code with GitHub Copilot**: our recommended setup from Week 1. Install [VS Code](https://code.visualstudio.com/) and follow [Set up your coding assistant](../../docs/SETUP.md#set-up-your-coding-assistant-week-1). We will help you get it working in the first session. You can use another coding assistant if you prefer.
- **Node.js v20 or later**: [Download here](https://nodejs.org/) (choose the LTS version)
- **Git**: [Download here](https://git-scm.com/) (Mac users: Git may already be installed; run `git --version` in Terminal to check)
- **A GitHub account**: [Sign up here](https://github.com/) if you don't have one
- **Git name and email**: see [Tell Git who you are](../../docs/SETUP.md#tell-git-who-you-are)
